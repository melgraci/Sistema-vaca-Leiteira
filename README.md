# 🐄 Sistema de Monitoramento de Produção de Leite

## 📌 Descrição

Este projeto consiste em um sistema web para monitoramento da produção de leite em uma fazenda. O objetivo é permitir o registro e acompanhamento de informações importantes, como produção diária, gastos operacionais e gerenciamento de funcionários.

O sistema foi desenvolvido com foco na experiência do usuário (UX), priorizando simplicidade, clareza e feedback visual nas interações.

---

## 🎯 Objetivo

Auxiliar no controle básico da produção leiteira, permitindo:

* Registro de produção de leite
* Controle de gastos
* Cadastro de funcionários
* Visualização geral no dashboard

---

## 🧩 Funcionalidades

### 🔐 Autenticação

* Login de usuário (simulado)
* Cadastro de usuário
* Recuperação de senha

### 📊 Dashboard

* Visão geral do sistema
* Acesso rápido aos módulos principais

### 🥛 Produção

* Cadastro de produção diária
* Validação de campos obrigatórios
* Feedback de sucesso ou erro
* Simulação de carregamento

### 💰 Gastos

* Registro de despesas
* Classificação por categoria
* Validação de dados
* Feedback ao usuário

### 👷 Funcionários

* Cadastro de funcionários
* Informações como nome, cargo e contato
* Validação de formulário


### ✔ Feedback ao usuário

* Alertas visuais com Bootstrap
* Mensagens claras de erro e sucesso

### ✔ Validação

* Campos obrigatórios em todos os formulários

### ✔ Navegação

* Menu lateral com acesso aos módulos
* Interface consistente em todas as páginas

---

## Fluxos Principais

### 1. Login

* Usuário insere dados
* Sistema valida
* Redireciona para o dashboard ou exibe erro

### 2. Cadastro de Produção

* Usuário preenche formulário
* Sistema valida dados
* Retorna mensagem de sucesso

### 3. Cadastro de Gastos

* Preenchimento de dados
* Validação
* Feedback ao usuário
